# Number Guessing Game

A simple browser-based number guessing game built with HTML, CSS, and JavaScript.

## How to Play

1. A random number between **1 and 10** is generated.
2. Enter your guess and click **Go** (or press **Enter**).
3. You get **3 attempts** — the game tells you if your guess is too high or too low.
4. Click **Restart** to play again.

## Features

- Too High / Too Low feedback
- Attempt indicator dots
- Clean dark UI
