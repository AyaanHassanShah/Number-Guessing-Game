# Number-Guessing-Game

A simple interactive number guessing game where the player tries to guess a randomly generated secret number within a set number of attempts. After each guess, the game provides feedback indicating whether the guess is too high, too low, or correct, helping the player zero in on the answer.

## How to Play

1. The game generates a random secret number within a defined range (e.g., 1–100).
2. Enter your guess when prompted.
3. The game tells you if your guess is **too high**, **too low**, or **correct**.
4. Keep guessing until you find the secret number or run out of attempts.

## Features

- Random number generation each round for replayability
- Helpful feedback after every guess
- Tracks the number of attempts taken
- Simple and beginner-friendly codebase
