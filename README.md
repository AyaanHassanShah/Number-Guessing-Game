# Number Guessing Game

A simple browser-based number guessing game built with HTML, CSS, and JavaScript.

## How to Play

1. A random number between **1 and 10** is generated.
2. Type your guess and click **Go**.
3. You have **3 attempts** — the game tells you if your guess is 📈 Too High or 📉 Too Low.
4. If you run out of attempts, the answer is revealed.
5. Click **↻ Restart** to play again with a new number.

## Features

- Too High / Too Low feedback after each guess
- Remaining attempts shown after each wrong guess
- Color-coded result messages (green = correct, red = too high, blue = too low, yellow = game over)
- Clean dark card UI with a gradient background
- Restart resets everything and picks a new random number
